What is HTML?

HTML is the standard markup language for creating web pages. It provides the structure of a website.

Key HTML Elements:

  • Headings (using tags like h1, h2, h3)
  • Paragraphs (using the p tag)
  • Lists (like this unordered list using ul and li tags)
  • Images (using the img tag)

What is CSS?

CSS is the language we use to style an HTML document. It describes how HTML elements should be displayed on the screen.

Basic CSS Concepts:

  • Class: Used to style multiple elements (written as .classname in CSS).
  • ID: Used to style one unique element (written as #idname in CSS).
  • Colors & Fonts: Simple properties to change how text looks.
