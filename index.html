Learn Basic HTML & CSS

A quick page covering the basics of web development.

What is HTML?

HTML stands for HyperText Markup Language and it is the standard markup language used to create and structure web pages.

HTML Examples:

  • <h1> - Big headings
  • <p> - Paragraphs of text
  • <ul> - Lists like this one
  • <img; - Pictures on a page

What is CSS?

CSS makes websites look pretty! It adds colors, sizes, and styles.

CSS Basics:

  • Colors - Make text and backgrounds colorful
  • Fonts - Change how text looks
  • Spacing - Add distance between things
  • Boxes - Make shapes and containers

How They Work Together

HTML builds the page. CSS (cascading style sheets) makes it look nice!
