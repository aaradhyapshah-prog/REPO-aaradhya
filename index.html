Basic of HTML & CSS

What is HTML?

HTML stands for HyperText Markup Language .it is a language used to create and structure web pages.

HTML Examples:

  • h1; -headings
  • p; - Paragraphs of text
  • ul and ol; - Lists lik
  • img; - Pictures on a page

What is CSS?

CSS stands for Cascading Style Sheets .IT adds design and layout to web pages.

CSS Basics:

  • Colors - Make text and backgrounds colorful
  • Fonts - Change how text looks
  • Spacing - Add distance between things
  • Boxes - Make shapes and containers

How They Work Together

HTML builds the page. CSS (cascading style sheets) adds design and layout.
